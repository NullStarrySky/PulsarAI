- `conversation-generation.ts`：`GenerationComponentRequest` 改为具体联合类型 `AgentInteractionRequest = { kind: "ask-user"; input: AskUserInput } | { kind: "ask-suggestion"; input: AskSuggestionInput }`；requester 注册函数同步改名；`requestUser`/`requestSuggestion` 直接传具体请求

- 移除 `skills`/`mcp` 空环境对象与 `createAgentExtensionApi` 导入；删除 `default-agent.ts` 中虚假的 "Registered Skill and MCP extensions..." 指令行
- `conversation-types.ts` 删除 `ComponentPart`（唯一生产者是被删的 `renderComponent`），`ConversationStageThread.vue` 删除 `componentParts` 渲染
- 更新 `AGENTS.md` 第 41–42 行硬规则（Skill/MCP 注册表与 ask-user 注册方式已不成立）与 `docs/事实来源.md` 的陈旧目录条目

## B. Plugin 重构

### B1. `.chat.json` 类型与编辑器升级
- `editors/chat/plugin-chat.ts`：消息项改为 `PluginChatMessage { role; content; name?: string; enabled?: boolean }`；`parsePluginChatContext` 校验两个新可选字段；`compilePluginChatContext` 过滤 `enabled === false` 的消息；`chatContextFormatPrompt` 补充说明
- `runtime/plugin-macros.ts` 的 `resolvePluginChatMacros` 同步跳过停用消息
- `PluginChatEditor.vue`：消息卡片头部加"命名"输入框（可选、作者侧标识）与启用 Switch；停用消息卡片置灰并标"已停用"；序列化时空 `name` 与 `enabled: true` 省略，保持 JSON 干净；旧数据无新字段完全兼容（含 SillyTavern 迁移写入器）

### B2. 面板结构调整
- `git mv Plugin/PluginAssetTreePanel.vue`、`Plugin/PluginFileEditorDialog.vue` → `Plugin/tree/`
- `git mv tree/PluginManagerPanel.vue` → `Plugin/`（特性根）
- 更新唯一引用 `ConversationStageOnePage.vue:7-9`

它是 `ctx.tools[name]` 与 `# 自定义工具` 引导块的唯一实现（`conversation-generation.ts` 消费），AGENTS.md 明确记载该约定，非残留。

### B4. Plugin 死代码清理
删除 `runtime/sandbox-api.ts`（零引用）、`assets/builtin-classroom-background.png`（零引用）。
