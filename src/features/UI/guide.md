# PulsarAI 界面设计规范

本文只定义界面设计规则，不记录功能清单、实现历史、命令契约或 Feature 所有权。

## 设计方向

- 面向桌面端生产力工具，强调高信息密度、清晰层级和稳定布局。
- 使用中性表面与单一主题强调色，不添加与状态、品牌或内容无关的装饰色。
- 优先依靠留白、分隔线、文字层级和表面明度表达结构；只有真实浮层、选中项和独立对象使用卡片或阴影。
- 动效短而克制。状态切换可以淡入或平移，持续操作和编辑器不得因动画阻塞。
- 所有颜色使用 `background`、`foreground`、`muted`、`border`、`primary`、`destructive` 等主题语义变量。

## 字体与信息层级

- 应用基础字号由外观设置控制；普通界面默认按 `14px` 视觉密度设计。
- 页面标题使用 `text-xl` 或 `text-lg`、半粗体和紧凑字距。
- 分区标题使用 `text-sm font-semibold`。
- 字段标题使用 `text-sm font-medium`；说明使用 `text-xs`、`text-muted-foreground` 和舒适行高。
- 文件 ID、路径、快捷键和代码使用等宽字体；普通标题和说明不使用等宽字体。
- 省略只用于单行导航、路径和紧凑摘要；影响操作判断的正文必须允许换行或展开。

## 间距、圆角与材质

- 基础间距单位为 `4px`。常用间距为 8、12、16、24、28px。
- 普通控件使用主题中等圆角；导航选中项和分段控件可以使用胶囊圆角；主浮窗使用 16px 左右的大圆角。
- 同一表面内不连续堆叠带边框卡片。设置字段默认使用无边框行，并以细分隔线分组。
- 阴影只用于浮窗、悬浮面板和需要与背景明确分层的选中卡片。
- 控件状态通过填充、文字、图标和透明度表达，不依赖浏览器默认 outline。

## 应用壳层

- Shell 占满 `100dvh`，自身不滚动；会话、资产面板和编辑器分别拥有内部滚动区域。
- 顶栏保持紧凑，交互控件使用统一灰度；背景与主工作区有轻微明度差，不使用强边框。
- 窄窗口下的浮动面板切换为抽屉或单栏布局，不压缩主要编辑内容到不可用宽度。
- 浮动资产、设置和编辑器不得改变消息主列宽度。

## 设置中心

- 设置中心使用一个居中的双栏浮窗。桌面端允许通过左侧顶部和内容标题栏拖动，并允许临时超出页面范围；移动端占满视口且不拖动。
- 左侧导航不显示分组标题，所有页面平铺；“快捷键”固定在顶部，设置标题旁显示打开设置的快捷键。
- 左侧搜索只过滤页面和一级 Tab，不改变持久化设置。
- 右侧顶部统一显示当前页面标题和关闭按钮。存在多个功能面时，在标题下使用一级胶囊 Tab。
- 页面组件不重复渲染页面标题或页面描述。
- 设置组不允许组描述，不使用组边框。组标题只在需要命名一段字段时显示。
- 字段使用“左侧标题与说明、右侧控件”的两列布局；窄于 `768px` 时回退为纵向排列。
- 字段之间使用细分隔线。复杂编辑器、测试结果或说明区可以占据整行底部区域。
- Provider、备份、统计等专用页面可以保留自身双栏或可视化结构，但应使用同一标题、行高、表面和滚动规范。

## 主题页面

- 顶部先显示浅色、深色、跟随系统的分段选择。
- 主题以紧凑网格呈现：色点、主题名和一行简述组成一个选项；只有当前主题使用选中表面和标识。
- 导入主题是次要操作，不得取代内置主题的直接选择。
- 字体、字号、缩放、自定义 CSS、代码预览和移动端选项必须保留在“自定义”区域，使用标准设置字段布局。
- 主题预览使用主题自己的强调色，不硬编码新的产品色。

## 动态配置与 Manifest

- `manifest.json` 的 Group 是一级功能 Tab，仅包含稳定 ID 和展示标题，不包含组描述。
- Tab 内容使用无边框设置行；字段仍可拥有标题、说明、控件、属性和值。
- 自定义组件必须服从当前主题、控件高度和两列字段布局，不自行创建第二套设置卡片样式。
- 配置的稳定 ID 只用于存储和引用；用户界面优先显示标题。

## 滚动与内容高度

- 应用拥有的设置内容、侧栏、树和长列表默认使用共享 `ScrollArea`，同时挂载垂直和水平滚动条。
- 编辑器、虚拟列表和媒体画布可以保留自己的滚动实现。
- 固定标题栏、Tab 和底部操作区不参与内容滚动；只有中间内容区域滚动。
- 内容较少时浮层保持紧凑；内容较多时受视口高度约束并出现滚动，不让整个页面产生双重滚动。

## 响应式与触控

- `768px` 是设置中心和主要双栏页面的显式回退点。
- 移动布局使用共享 responsive state，不在 Feature 内重复读取视口宽度。
- 触控目标至少保持约 40px；桌面紧凑控件可以更小，但必须保留清晰命中区域。
- 移动端设置导航使用抽屉，内容保持单栏；桌面拖拽和悬停专属操作必须有触控替代入口。

## 状态与反馈

- 加载、空内容、错误和禁用状态必须在所属区域内表达，不依赖控制台信息。
- 危险操作使用 `destructive` 语义色并要求明确确认；普通保存和自动保存不持续抢占注意力。
- 选中状态必须能通过表面或图标识别，不能只依赖颜色差异。
- 自动保存界面只显示必要结果，例如上次保存时间或错误，不展示内部节流与间隔参数。
