# About

`About` owns the compact settings page for application identity, version, update preference, manual update checks, and release notes.

The page presents the shared PulsarAI application icon in its identity header. The icon keeps its monochrome artwork while the shared UI wrapper supplies theme-aware edge contrast for light and dark appearances.

The page intentionally omits log-directory and copyright actions. Its Done button closes the shared Settings dialog rather than creating a second modal shell.
