# PulsarAI 角色包架构

> 本文档是角色包架构的事实来源，面向项目内部 LLM、开发者和代码审查流程。

## 1. 职责与边界

角色包承担以下职责：

- 作为用户角色、Conversation 和本地资源的归属边界；
- 选择当前角色使用的主插件和全局插件；
- 为导入、导出、同步和删除提供完整资源边界。

角色包不是系统角色，也不是插件内容的副本。每个角色包恰好拥有一个本地插件；Conversation 通过 `packageId` 归属于角色包，插件通过稳定 ID 与角色包建立关系。

## 2. 数据模型

```ts
export interface CharacterPackage {
  id: string; // 稳定角色包 ID
  name: string; // 展示名称
  icon: string; // 展示图标
  description: string; // 角色包说明
  categoryId: string | null; // 所属分类
  treeOrder: number; // 分类内展示顺序
  pluginId: string; // 唯一本地插件 ID
  mainPluginId: string; // 生成流程及固定生成配置所属插件 ID
  enabledGlobalPluginIds: string[]; // 已启用全局插件 ID 的无序集合
}

export interface CharacterPackageCategory {
  id: string; // 稳定分类 ID
  name: string; // 展示名称
  treeOrder: number; // 展示顺序
}
```

角色包不保存 Conversation 数组；Conversation 的 `packageId` 是归属关系的唯一事实来源。分类只用于组织角色包，不影响生成、权限或插件解析。

## 3. 生命周期

创建角色包时，在同一事务中创建其本地插件，并默认将该插件设为主插件。删除角色包时同时删除所属 Conversation、本地插件和派生数据，但不删除全局插件。删除分类只会令其中角色包变为未分类。

## 4. API

```ts
export interface CharacterPackageCreateInput {
  name: string;
  icon?: string;
  description?: string;
  categoryId?: string | null;
}

export type CharacterPackagePatch = Partial<Pick<
  CharacterPackage,
  "name" | "icon" | "description" | "categoryId" | "treeOrder"
>>;

export interface CharacterPackageApi {
  list(): CharacterPackage[];
  get(packageId?: string): CharacterPackage | null;
  create(input: CharacterPackageCreateInput): Promise<CharacterPackage>;
  update(packageId: string, patch: CharacterPackagePatch): Promise<CharacterPackage>;
  remove(packageId: string): Promise<void>;

  setMainPlugin(packageId: string, pluginId: string): Promise<CharacterPackage>;
  setGlobalPluginEnabled(
    packageId: string,
    pluginId: string,
    enabled: boolean,
  ): Promise<CharacterPackage>;

  listCategories(): CharacterPackageCategory[];
  createCategory(input: { name: string }): Promise<CharacterPackageCategory>;
  updateCategory(
    categoryId: string,
    patch: Partial<Pick<CharacterPackageCategory, "name" | "treeOrder">>,
  ): Promise<CharacterPackageCategory>;
  removeCategory(categoryId: string): Promise<void>;
}
```

`get()` 省略 ID 时返回当前执行上下文的角色包。`setMainPlugin()` 会自动启用目标全局插件；主插件不能被直接停用，必须先切换。所有写操作返回数据库提交后的结果。

角色包 API 不复制 Conversation API。对话的创建、查询和消息操作由 Conversation Feature 持有。`remove()` 属于破坏性操作，在未授权的 Sandbox 中必须从实际 API 对象移除。
