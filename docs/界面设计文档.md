## 1. 设计规范总结（从 Codex 页面提取）

### 字号
| 用途 | 类名 / 值 | 说明 |
|------|-----------|------|
| 对话正文 | `text-size-chat` | ≈15px，`line-height: 1.5rem` |
| 次要正文 | `text-size-chat-sm` | ≈13px |
| 标题 / Header | `text-base font-medium` | 16px，中等字重 |
| 时间戳 / 元信息 | `text-xs` | 12px，`text-token-text-tertiary` |
| 工具栏标签 | `text-sm` | 14px |
| 强调 | `font-semibold` | 600 |

### 颜色（Token 体系，暗色优先）
| Token | 用途 |
|-------|------|
| `token-foreground` / `token-text-primary` | 主文字 |
| `token-text-secondary` | 次要文字、状态行 |
| `token-text-tertiary` | 时间、图标、弱提示 |
| `bg-token-foreground/5` | 用户消息气泡背景 |
| `bg-token-list-hover-background` | 按钮 / 列表 hover |
| `bg-token-text-code-block-background` | 代码块背景 |
| `border-token-border` / `border-token-border-default` | 分割线、边框 |
| `ring-token-focus-border` | 焦点环 |
| `bg-token-main-surface-primary` | 主背景 |
| `bg-token-dropdown-background` | Composer / 浮层 |

### 图标尺寸（原型中已全部清除，用占位块代替）
- `icon-xs` ≈ 20×20
- `icon-sm` ≈ 21×21
- `icon-2xs` ≈ 16×16
- 按钮多为 `rounded-full` + `p-0.5` / `p-1`

### 间距与圆角
- 消息间距：`--conversation-item-gap: 16px`
- 用户气泡：`max-w-[77%]` + `px-3 py-2` + `rounded-2xl`
- 常用 gap：`0.5` / `1` / `1.5` / `2` / `3`
- Header 标题：`max-w-[320px] truncate`
- 内容区：`max-w-(--thread-content-max-width)`（约 48rem）居中
- Composer：`rounded-3xl`，底部 sticky

### Markdown 规则（已对齐到 Milkdown）
- `p + p` → `mt-5`
- `ul` / `ol` → `ps-6`
- `li + li` → `mt-0`
- 行内 code / 代码块使用 code-block 背景与圆角
- `strong` → `font-semibold`

### 字体与排版
| 元素 | 规范 |
|------|------|

| Markdown h3 | 同体系，稍小层级 |
| 行高 / 字距 | `leading-normal tracking-normal` |

### 颜色（Token 语义）
- 前景主色：`text-token-foreground`
- 次要文字：`text-token-text-secondary` / `text-token-text-tertiary`
- 边框：`border-token-border` / `border-token-border-default`（含 `/70`）
- 主内容区背景：`bg-token-bg-primary/40`
- 开关开启：`bg-token-charts-blue`
- 按钮主色：`bg-token-foreground` + 文字 `text-token-dropdown-background`
- 悬停：`hover:bg-token-list-hover-background` / `hover:bg-token-toolbar-hover-background`
- 焦点环：`ring-token-focus-border`

### 图标
| 位置 | 尺寸 | 说明 |
|------|------|------|
| 头部主图标（GitHub 风格） | 外框约 `h-10 w-10`，内 SVG `24×24`，`rounded-lg` 边框 | `text-token-text-secondary` |
| 右上角操作（更多 / 关闭） | `21×21` 或 `icon-xs` | 透明底 |
| 底部按钮图标 | `14×12` 左右 | 与文字并排 |
| 开关滑块 | 轨道 `h-5 w-8`，圆点 `h-4 w-4` | 选中时 `translate-x-[14px]` |

### 间距与布局
- 外层纵向：`flex flex-col gap-0`，区块 `pt-3 first:pt-0`
- 头部图标 + 文字：`gap-3`，文字内部 `gap-1` / `gap-2`
- 内容区滚动容器：`rounded-xl border ... p-4`，整体 `opacity-80`
- 底部按钮区：`justify-end` / `justify-between`，`gap-2` / `gap-3`
- 右上角操作组：`absolute top-5 right-5`，`gap-1` / `gap-2`
- 按钮高度近似 `h-token-button-composer`，`rounded-lg`，`px-2 py-0`

### 其他
- 无障碍：`role="dialog"`，`aria-labelledby` / `aria-describedby`，标题/描述可用 `sr-only`
- Markdown 区域可滚动（`overflow-y-auto`），外层 `min-h-0 flex-1`
- 开关为 Radix 风格 `role="switch"`
